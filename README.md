# Project Report & Evidence Repository

This repository contains the project documentation, screenshots, network scan output, and packet capture evidence for the security/networking task completed as part of the CloudExify internship work.

## Project Overview
This project focuses on network analysis and security assessment using:
- Nmap scanning for host and port discovery
- Wireshark analysis for packet inspection
- Review of services and network behavior
- Collection of visual evidence through screenshots
